# AI Resume Screening System

## Overview

AI Resume Screening System is a Retrieval-Augmented Generation (RAG) based application that helps recruiters automate resume screening and candidate ranking.

The system allows recruiters to:

- Upload resumes in PDF format
- Extract and store resume content
- Generate embeddings for semantic search
- Match resumes against job descriptions
- Rank candidates using Gemini AI
- View AI-generated explanations for rankings

# Candidate Ranking Formula

## AI Match Score

Generated by Gemini using:

- Skills
- Projects
- Experience
- Education
- Job Description

## Similarity Score

Generated using:

- Resume Embeddings
- Job Description Embeddings
- Cosine Similarity

## Final ATS Score

```text
Final ATS Score =
(AI Match Score × 0.7)
+
(Vector Similarity × 0.3)
```

Candidates are ranked in descending order of Final ATS Score.

# API Endpoints

## Resume APIs

### Upload Resume

```http
POST /upload-resume
```

### Get All Resumes

```http
GET /resumes
```

### Get Resume By ID

```http
GET /resume/{id}
```

### Delete Resume

```http
DELETE /resume/{id}
```

---

## Candidate Ranking API

```http
POST /rank-candidates
```

### Request

```json
{
  "job_description": "Python Developer with FastAPI and MongoDB",
  "top_k": 5
}
```

### Response

```json
[
  {
    "candidate": "Mayank Pathak",
    "match_score": 95,
    "similarity_score": 88.5,
    "final_score": 93.05,
    "reason": "Strong FastAPI, MongoDB and AI project experience."
  }
]
```

# Backend Setup

## Create Virtual Environment

```bash
cd Backend

python -m venv venv
```

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```
